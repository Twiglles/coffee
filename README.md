# Пять самостоятельных маршрутов Рязани

Каждая из пяти пронумерованных папок — отдельный полный проект. В каждом проекте один маршрут, пять остановок и собственный счётчик. Кнопки выбора других маршрутов нет. Чужие маршруты удалены из данных и логики.

1. `01-ryazanskoe-knyazhestvo` — «Рязанское княжество».
2. `02-ryazan-kotoruyu-my-teryaem` — «Рязань, которую мы теряем».
3. `03-ryazan-serebryanogo-veka` — «Рязань Серебряного века».
4. `04-sovetskiy-shik` — «Советский шик города Р.».
5. `05-ryazan-saltykova-shchedrina` — «Рязань Салтыкова-Щедрина».

В каждой папке находятся исходники, готовая сборка, все изображения и шрифты, локальная карта, серверный счётчик, схема базы, политика и согласие, инструкции запуска и публикации. Зависимости от соседних папок нет. Переносите любую папку целиком.

## Проверить все пять

Нужен Node.js 24 или новее. В общей папке выполните:

```text
node build-all.mjs
node preview-all.mjs
```

Откроются локальные адреса http://localhost:4171 … http://localhost:4175 — по одному проекту на порт. Остановить серверы: Ctrl+C. Для теста без сохранения счётчиков используйте `node preview-all.mjs --memory`.

Или запускайте любую папку отдельно по инструкции в её README. Библиотеки через npm устанавливать не нужно.

## Публикация и QR

Это пять отдельных пакетов для размещения на пяти адресах. Публичные адреса новым проектам ещё не назначены. Сайт для согласования не является одной из этих пяти публикаций. При размещении каждого проекта его адрес `/` открывает единственный маршрут, а `/qr` используется в печатном QR-коде и учитывает открытия. Каждый сервер хранит собственную статистику. Новые базы стартуют с нуля; статистика общей версии для согласования сюда не переносится.

Общий счётчик требует сервер и базу; одного копирования HTML на статический хостинг для него недостаточно. Предусмотрены Node.js + SQLite и Worker + D1. На опубликованном сайте нужен HTTPS для геолокации. Ключей, токенов, рабочих баз посетителей и идентификатора общей публикации в архиве нет.

Политика и согласие содержат согласованные данные ИП Зенушкиной Евгении Игоревны и twiglles@yandex.ru. Адрес сайта в тексте — coffee.twiglles.com; перед размещением на другом домене его можно изменить в legal/operator.json.

## Проверки перед передачей

`node verify-projects.mjs` проверяет каждый проект отдельно: фиксированный маршрут, запрет переключения параметром ссылки, пять остановок, открытие описаний без сдвига точек, согласие на GPS, возврат к маршруту, отдельный счётчик, отклонение чужого номера маршрута и отсутствие идентификатора общей публикации. Проверки используют временные базы и не изменяют рабочую статистику.
