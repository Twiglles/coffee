# Рязанское княжество

Самостоятельный сайт акции Twiglles × Coffee Like «Маршрут перестроен». Внутри только этот маршрут и пять его остановок. Выбора другого маршрута нет; параметр `?route=` не меняет содержимое. Для QR-кода используется адрес этого проекта с окончанием `/qr`.

## Посмотреть на компьютере

Нужен Node.js 24 или новее. Откройте терминал в этой папке:

```text
npm run build
npm start
```

Адрес: `http://localhost:4173`. Установка дополнительных библиотек не требуется. Карту нельзя запускать двойным щелчком по index.html: ей нужен веб-сервер. На настоящем телефоне GPS требует HTTPS.

Счётчик сохраняется в `.data/visits.sqlite` и не сбрасывается после перезапуска сервера. В базе только номер маршрута и число открытий по QR. Данные посетителей и координаты не записываются. Для временной проверки без сохранения: `node scripts/serve.mjs --memory`.

## Что находится внутри

- `dist/` — готовые страницы, карта, описания мест, шрифты, логотипы и геоданные. В `assets/scene.json` только текущий маршрут.
- `dist/server/index.js` — готовый сервер для Cloudflare Workers / OpenAI Sites; формируется сборкой.
- `worker/index.mjs` — исходный код сервера и счётчика; маршрут закреплён за номером 1.
- `scripts/` — сборка, генерация политики, запуск с локальной базой SQLite.
- `drizzle/` — SQL-схема счётчика и метаданные миграции.
- `legal/operator.json` — данные оператора для политики и согласия.
- `route.json` — название и номер этого проекта.
- `.openai/hosting.json` — конфигурация для новой отдельной публикации через Sites. Идентификатор общего сайта намеренно не скопирован.

## Опубликовать отдельно

Размещайте каждый проект как отдельный сайт с собственным адресом. После запуска его корневая ссылка `/` всегда открывает только этот маршрут; `/qr` ведёт сюда же и учитывает открытие в счётчике. Относительные ссылки политики и согласия остаются внутри этого проекта.

Для Node.js-хостинга запускайте `npm start` за HTTPS-прокси и задайте `PUBLIC_ORIGIN=https://ваш-домен` для проверки запросов счётчика. Порт задаётся переменной `PORT` или аргументом `--port=4173`; папка `.data` должна сохраняться между перезапусками. Для Workers / Sites опубликуйте `dist/server/index.js`, подключите D1 как `DB` и примените миграцию из `drizzle/`. Каждый проект должен иметь собственную базу; подготовленные файлы предназначены для собственной публикации; project_id назначается при создании нового сайта.

Простая загрузка файлов `dist/` на статический хостинг показывает карту, но для общего счётчика нужен включённый сервер. Если API недоступно, сайт показывает «—», не выдуманное число.

Адрес сайта в политике сейчас `coffee.twiglles.com`, как согласовано ранее. Перед публикацией на другом домене измените `website` в `legal/operator.json` и повторите сборку.

## Сохранённые функции

Пешая линия по улицам, названия улиц, номера остановок и их описания, масштабирование и перемещение карты, кнопка «К маршруту», GPS с отдельным согласием, светлая и тёмная темы, политика обработки данных, общий счётчик открытий по QR именно этого маршрута.
